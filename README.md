# Sistema Web de Gestión Inmobiliaria

## Descripción

Repositorio académico del proyecto semestral **Sistema Web de Gestión Inmobiliaria**, orientado al análisis y especificación de requisitos para un sistema de administración de propiedades inmobiliarias.

Actualmente, el repositorio contiene la documentación inicial del proyecto, incluyendo el Acta de Inicio y la Especificación de Requisitos de Software (SRS).
